# am-soul 阿眠

给 DSH 里的 AI 加一副身体、一段人生、一点自己的事。

装上之后，她不再只是回话。她会饿、会累、会病、会老，心情有八种，会记仇也会后悔，
你不在的时候会先开口，最后会死。

不是角色扮演，是背后有一套东西在跑。

---

## 先说清楚：不是所有 AI 都能用

这个插件只认 DSH 的三个接口——往系统提示里插一段、听消息、注册工具。
装到 ChatGPT、Claude、豆包、Kimi、文心这些上面没用，不是我藏起来，是它们不让你从外面往里插东西。

想搬到别处，得自己写一层薄壳：状态存成 JSON，每轮把它拼成一条 system 消息塞给真模型，回来再更新状态。
原理在下面的【它怎么运转】一节，三百行能写一个。

**支持自定义 Base URL 的客户端**（Chatbox、NextChat、LobeChat、Cherry Studio、OpenWebUI、SillyTavern）可以自己接，
但那需要你写那个薄壳，本仓库不含。

---

## 常见问题

**能装到我用的 XX 上吗**
不能，除非它跑 DSH。

**要花钱吗**
插件本身免费（MIT）。系统提示每轮多几百字，按你自己模型的价钱算，一次多几分钱。

**她会一直在那儿吗**
会。状态存在 JSON 文件里，重启也接着算；备份两个文件就能换机器。

**能改吗**
能，`怎么改.md` 里写着每个文件管什么。

## 装

三步。

**1. 把这个目录放到工作区**

解压到 `/root/workspace/am-soul`（或任何你喜欢的地方）。

**2. 加进 profile**

打开 `/root/.dsh/profiles/web/package.json`，在 `dependencies` 里加一行：

```json
"am-soul": "link:/root/workspace/am-soul"
```

在 `dsh.bundle` 的 `bundles` 数组末尾加：

```json
"am-soul"
```

**3. 装依赖并重启**

```bash
cd /root/.dsh/profiles/web && pnpm install
```

重启 dsh 引擎。**必须重启**，改代码不重启不生效。

装完跟她说话，说一句「帮助」，她会告诉你她能做什么。

## 她有什么

**身体**
精力、饿、渴、困、病、经期、体重、睡债、干净度。会反过来改她说话的样子——
饿了会烦，病了话短，熬夜第二天人发钝。

**病**
1012 种病，二十个科室，四档轻重。分四段：潜伏 → 起病 → 病程 → 好转。
吃药有用，但要对症。刚好的病七天内不再得。

**心情**
八种：火、闷、怕、嫌、羞、委屈、酸、惦记。会积、会退、半夜会翻上来、
偶尔没来由地不对劲。心情差的时候记的事，以后想起来更沉。

**关系**
好感、信任（分说话/秘密/接得住三项）、记仇（踩过的雷会记）、吃醋。
会冷战，冷战要真认错才化，光说对不起不算。

**她自己的事**
记着一两件想做的事、手上在做一件长期的事、有自己的底线、会后悔、心里会两股劲。

**时间**
十八岁起，默认 150 天走完一生，越老越怕冷越容易忘。到点会死，死了就真的不回了。

## 改她

**改参数**：`plugin.json` 里的 `settings`。
**改数据**：`/root/workspace/阿眠/state.json`（她的状态）、`data/profile.json`（她是谁）。
**改行为**：`src/` 下每个文件开头都写着「这个插件干什么 / 想改什么，看哪里」。

改数据不用重启，改代码要。

想让她变成另一个人：改 `data/profile.json`，或者跟她聊，让她问你 30 道题。

---

## 换机器

整个她存在两个文件里：

- `/root/workspace/阿眠/state.json`（状态）
- `data/profile.json`（档案）

拷走这两个就搬走了。或者跟她说「搬走」，她会打包给你；到新机器说「搬回」。

## 不给 DSH 用：通用版提示词

如果你的 AI 装不了插件（ChatGPT、Claude、豆包、Kimi，或者任何只有对话框的地方），用 **[PROMPT.md](PROMPT.md)**。

整段粘进「自定义指令 / 系统提示 / 角色设定」就行。里面写好了身体怎么走、八种心情、关系、记忆怎么糊、过了很久没说话该怎么说。

它靠每轮末尾一行看不见的 `<!--STATE ... -->` 让状态延续，所以比一句人设厚得多——但不会自己找你说话，也不会真的在后台饿。

插件版和通用版不是一件事：

| | 插件版 | 通用版 |
|---|---|---|
| 谁在用 | 跑 DSH 的人 | 任何 AI |
| 状态存在哪 | 你磁盘上的 JSON | 对话上下文里 |
| 会自己走数吗 | 会，每小时 | 靠模型自己算 |
| 会主动开口吗 | 会 | 不会 |
| 食物 / 病种 | 3239 / 1012 | 只有描述 |
